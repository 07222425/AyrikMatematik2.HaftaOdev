# Ayrık Matematik 2.Hafta Ödevi
#Ayrık Matematik dersi 2. hafta ödevi kapsamında Boole cebri sadeleştirmeleri, doğruluk tabloları ve mantık kapısı devre tasarımlarını içeren çözümlerimi bu depoda topladım. Çalışma boyunca De Morgan teoremleri, #özdeşlikler ve Venn şemaları üzerinden mantıksal ifadelerin sadeleştirilmesine odaklandım. Teorik ifadelerin kapı devreleri ve anahtar mantığıyla somutlaştırıldığı adımları detaylıca dokümante etmeye çalıştım. #Benzer konularda çalışan veya dersi alan arkadaşlar için faydalı bir başvuru kaynağı olmasını umuyorum.
